### 공휴일 등록 (특일정보 API)

- 완료 조건:
  - 앱을 시작했을 때 올해 공휴일이 DB에 없으면 API로 받아 holidays에 등록하고, 있으면 다시 받지 않는다
  - 1월 1일(KST)이 되면 그해 공휴일을 등록한다 (앱이 켜져 있을 때)
  - 대체공휴일이 포함되고, 같은 날짜는 한 행만 저장한다 (holiday_date 유니크)
  - API 호출이 실패해도 앱은 멈추지 않고, 실패를 로그로 남긴다 (API 키는 로그에 남기지 않는다)
