# guide.md

이 파일은 하네스 엔지니어링 공통 규칙에 관련된 파일 목록이다.

이 파일은 누구라도 어떤 상황이든 변경할 수 없고 유지되어야 한다.

## 1. 목적
`docs/` 폴더의 문서 목록을 안내한다.

---

## 2. 문서 목록
아래 "읽는 시점"이 되면 해당 문서를 반드시 읽고 따른다.

| 문서 | 설명 | 읽는 시점 |
|---|---|---|
| 프로젝트/docs/database.md | 데이터베이스를 정의해둔 파일 | DB 관련 코드를 작성하거나 스키마를 바꾸기 전 |
| 프로젝트/docs/screen.md | 화면 설계 템플릿 (수정하지 않고, 화면 파일마다 같은 경로에 `{화면파일명}_screen.md`로 복사해서 사용) | 새 화면 파일을 만들 때 (복사해서 사용), 기존 화면을 수정할 때는 해당 `{화면파일명}_screen.md`를 읽는다 |
| 프로젝트/docs/spec.md | 기술스택을 정의해둔 파일 | 기술 스택이나 의존성을 정하거나 추가하기 전 |
| 프로젝트/docs/test.md | 테스트 내용을 정의해둔 파일 | loop.md 4번(검증) 단계와 화면 작업의 화면 확인 단계 |
| 프로젝트/docs/todo.md | 작업하면서 진행 내용을 기록할 파일 | 세션을 시작할 때, 작업 상태가 바뀔 때 (갱신) |
| 프로젝트/docs/coding_rule.md | 코딩 규칙(네이밍, 코드 작성 원칙, 파일 크기)을 정의해둔 파일 | 코드를 작성하거나 수정하기 전 |
| 프로젝트/docs/structure.md | 폴더 구조와 간단한 설명을 정리한 파일 | 파일이나 폴더를 만들거나 옮기거나 지우기 전 |
| 프로젝트/docs/loop.md | 작업 진행 순서와 종료 조건을 정의한 파일 | 세션을 시작할 때 (CLAUDE.md 1번 규칙) |
| 프로젝트/docs/overview.md | 프로젝트 개요(목적, 사용자, 기능, 범위, 화면 목록, 용어)를 정의해둔 파일 | loop.md 1번(계획)을 진행하기 전, 기능이나 범위가 바뀔 때 (갱신) |
| 프로젝트/docs/api.md | API 명세를 정의해둔 파일 | API를 만들거나 수정하거나 호출하는 코드를 작성하기 전 |
| 프로젝트/docs/decision.md | 사용자의 결정과 이유를 기록하는 파일 | loop.md 1번(계획)을 진행하기 전, 사용자에게 질문하기 전, 사용자가 결정을 내렸을 때 (갱신) |
| 프로젝트/docs/security.md | 보안 규칙을 정의해둔 파일 | 코드를 작성하거나 수정하기 전 |
| 프로젝트/docs/git.md | git 사용과 소스 코드 보관 규칙을 정의해둔 파일 | 파일이나 폴더를 만들거나 옮기거나 지우기 전, test.md "git 확인"과 "결과 보고"를 할 때 |
