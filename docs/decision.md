# decision.md

사용자가 내린 결정과 그 이유를 기록하는 문서다. 세션이 바뀌어도 같은 질문을 반복하지 않기 위해 쓴다.

## 운영 규칙
- 질문에 대한 사용자의 답, 사용자가 선택한 방법은 결정 즉시 기록한다.
- 질문하기 전에 이 문서를 확인한다. 이미 결정된 내용은 다시 묻지 않는다.
- 사용자의 요청이 기존 결정과 다르면, 기존 결정을 알리고 바꿀지 확인한다.
- 결정은 지우지 않는다. 결정이 바뀌면 기존 항목의 상태를 "변경됨"으로 바꾸고 새 항목을 추가한다.
- 결정 때문에 다른 문서(overview.md, spec.md 등)를 바꿔야 하면 그 문서도 함께 갱신한다.

### D-036 뉴스레터 설정 관리와 스케줄
- 날짜: 2026-10-03
- 질문/상황: 자동 생성/발송 시각
- 결정: 뉴스레터 생성 시간과 발송 시간을 설정하는 "뉴스레터 설정 관리" 페이지를 따로 만든다. 스케줄러는 생성 시간에 뉴스레터를 생성하고, 발송 시간에 미발송된 가장 최근 뉴스레터를 전체 수신자에게 발송한다. 관리자 확인은 없다. 관리자의 생성/발송 버튼은 시간과 상관없이 언제든 누를 수 있다. 자동 실행은 KST 기준이며, 한국 기준 주말, 공휴일, 대체공휴일에는 하지 않는다.
- 이유: 사용자 요구 (D-004의 "8시 고정", D-005의 "8시 자동 발송"을 대체)
- 관련 문서/파일: overview.md, database.md
- 상태: 유효
