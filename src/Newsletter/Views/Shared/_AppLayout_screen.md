# _AppLayout_screen.md

로그인한 사용자 화면의 공통 레이아웃(좌측 네비게이션) 설계 문서다. docs/screen.md 템플릿을 복사해서 작성했다.

화면을 바꾸는 작업에서는 이 문서도 함께 갱신한다.

---

## 1. 기본 정보

- **화면 파일 경로**: 프로젝트/src/Newsletter/Views/Shared/_AppLayout.cshtml
- **화면 이름**: 로그인 후 공통 레이아웃 (좌측 네비게이션)
- **화면 목적**: 로그인한 사용자에게 권한별 메뉴와 로그아웃을 보여주고, 각 화면 내용을 오른쪽에 표시한다 (D-049)
- **접근 URL**: 이 레이아웃을 쓰는 모든 화면 (/History, /Admin/Send, /Admin/Recipients, /Admin/Settings 등)
- **접근 권한**: 일반 사용자, 관리자 (로그인 필요)
- **시안 파일 경로**: 프로젝트/docs/mockups/app_layout.html
- **연결 파일**: 프로젝트/src/Newsletter/wwwroot/js/app_layout.js (로그아웃), 프로젝트/src/Newsletter/wwwroot/css/app_layout.css

---

## 2. 레이아웃

| 영역 | 위치 | 내용 |
|---|---|---|
| 좌측 네비게이션 | 왼쪽 고정 (너비 220px, 화면 높이 전체) | 서비스 이름, 메뉴, 로그아웃 버튼 (사용자 이름과 권한은 표시하지 않음, D-074) |
| 본문 | 네비게이션 오른쪽 | 각 화면 내용 (화면 제목 + 내용) |

### 반응형 기준
- 모바일 대응은 하지 않는다 (D-012). 네비게이션 너비는 220px로 고정한다.

---

## 3. 화면 요소

| 요소 | 종류 | 표시 내용 | 데이터 출처 | 비고 |
|---|---|---|---|---|
| 서비스 이름 | 텍스트 | "뉴스레터" | 고정 문구 | 네비게이션 맨 위 |
| 메뉴: 뉴스레터 발송 | 링크 | "뉴스레터 발송" | | /Admin/Send. 관리자만 |
| 메뉴: 수신자 관리 | 링크 | "수신자 관리" | | /Admin/Recipients. 관리자만 |
| 메뉴: 뉴스레터 설정 관리 | 링크 | "뉴스레터 설정 관리" | | /Admin/Settings. 관리자만 |
| 메뉴: 히스토리 | 링크 | "히스토리" | | /History. 관리자, 일반 사용자 |
| 현재 메뉴 표시 | 배경색 | 지금 보고 있는 화면의 메뉴를 강조 | 요청 경로 | 부트스트랩 nav-pills active |
| 로그아웃 버튼 | 버튼 | "로그아웃" | | 네비게이션 맨 아래 |

- 메뉴 순서는 overview.md 화면 흐름(관리자: 뉴스레터 발송 → 수신자 관리 → 뉴스레터 설정 관리 → 히스토리)을 따른다.
- 아직 만들지 않은 화면(수신자 관리, 뉴스레터 설정 관리)의 메뉴도 표시한다. 해당 작업 전까지는 누르면 404가 나온다.

## 4. 동작

| 요소 | 사용자 동작 | 결과 |
|---|---|---|
| 각 메뉴 | 클릭 | 해당 화면으로 이동 |
| 로그아웃 버튼 | 클릭 | POST /api/auth/logout 호출 후 로그인 화면(/Account/Login)으로 이동. 호출이 실패해도 로그인 화면으로 이동한다 |
| (로그인 만료) | 60분 동안 요청이 없어 쿠키가 만료된 뒤 화면 이동 | 로그인 화면으로 이동 (D-060) |

## 5. 데이터

|---|---|---|
| POST | /api/auth/logout | 로그아웃 (인증 쿠키 삭제) |

### 사용 테이블
