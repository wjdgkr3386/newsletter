# Settings_screen.md

뉴스레터 설정 관리 화면 설계 문서다. docs/screen.md 템플릿을 복사해서 작성했다.

화면을 바꾸는 작업에서는 이 문서도 함께 갱신한다.

---

## 1. 기본 정보

- **화면 파일 경로**: 프로젝트/src/Newsletter/Views/Admin/Settings.cshtml
- **화면 이름**: 뉴스레터 설정 관리
- **화면 목적**: 관리자가 뉴스레터 자동 생성 시간과 자동 발송 시간을 분 단위로 보고 바꾼다 (D-036, D-043)
- **접근 URL**: /Admin/Settings
- **접근 권한**: 관리자 (일반 사용자는 히스토리 목록으로 이동, 비로그인은 로그인 화면으로 이동)
- **시안 파일 경로**: 프로젝트/docs/mockups/settings.html
- **연결 파일**: 프로젝트/src/Newsletter/wwwroot/js/settings.js, 프로젝트/src/Newsletter/wwwroot/css/settings.css

| 저장 버튼 | 버튼 (파란색) | "저장" | | 바꾼 값이 있고 시간이 올바를 때만 활성 |

## 4. 동작

| 요소 | 사용자 동작 | 결과 |
|---|---|---|
| 화면 | 열기 | GET /api/newsletter-settings로 지금 설정을 불러와 선택 상자에 채운다 |
| 시·분 선택 상자 | 값 바꿈 | 바로 생성 시간 < 발송 시간인지 검사한다. 아니면 빨간 테두리와 시간 오류 메시지를 보이고 저장 버튼을 끈다. 맞고 저장된 값과 다르면 저장 버튼을 켠다 |
| 저장 버튼 | 클릭 | POST /api/newsletter-settings 호출. 성공하면 성공 알림, 저장된 값을 새 기준으로 삼고 저장 버튼을 끈다. 실패하면 오류 알림 (INVALID_SETTING_TIME은 시간 오류 메시지 자리에 표시) |

## 5. 데이터

### 사용 API
| 메서드 | 경로 | 용도 |
|---|---|---|
| GET | /api/newsletter-settings | 지금 설정 조회 |
| POST | /api/newsletter-settings | 설정 저장 |

### 사용 테이블
- newsletter_settings (generate_time, send_time). last_generate_date, last_send_date는 표시하지 않는다 (D-079)

## 6. 상태별 화면

| 상태 | 표시 내용 |
|---|---|
| 로딩 중 | 카드 자리에 "불러오는 중..." |
| 불러옴 (바꾼 값 없음) | 지금 설정 표시, 저장 버튼 비활성 |
| 바꾼 값 있음 (올바름) | 저장 버튼 활성 |
| 시간 오류 (생성 ≥ 발송) | 생성·발송 선택 상자 빨간 테두리, 시간 오류 메시지, 저장 버튼 비활성 |
| 저장 중 | 저장 버튼 비활성, 문구 "저장 중..." |
| 저장 성공 | 초록 알림 "설정을 저장했습니다.", 저장 버튼 비활성 |
| 서버 오류 | 빨간 알림 "오류가 발생했습니다. 잠시 후 다시 시도해 주세요." |
| 데이터 없음 | 해당 없음 (설정 1행은 항상 있음) |
