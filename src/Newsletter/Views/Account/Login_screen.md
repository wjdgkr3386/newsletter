# Login_screen.md

로그인 화면 설계 문서다. docs/screen.md 템플릿을 복사해서 작성했다.

화면을 바꾸는 작업에서는 이 문서도 함께 갱신한다.

---

## 1. 기본 정보

- **화면 파일 경로**: 프로젝트/src/Newsletter/Views/Account/Login.cshtml
- **화면 이름**: 로그인
- **화면 목적**: 회원이 아이디와 비밀번호로 로그인한다. 로그인하면 권한에 따라 첫 화면으로 이동한다 (D-048)
- **접근 URL**: /Account/Login (루트 주소 /도 로그인하지 않았으면 이 화면으로 이동, D-071)
- **접근 권한**: 비회원. 이미 로그인했으면 권한별 첫 화면으로 이동한다 (D-072)
- **시안 파일 경로**: 프로젝트/docs/mockups/login.html
- **연결 파일**: 프로젝트/src/Newsletter/wwwroot/js/login.js, 프로젝트/src/Newsletter/wwwroot/css/login.css

## 2. 레이아웃

| 영역 | 위치 | 내용 |
|---|---|---|
| 상단 제목 | 화면 가운데 카드 상단 | 서비스 이름 "뉴스레터", 화면 제목 "로그인" |
| 전체 오류 알림 | 제목 아래 | 로그인 실패, 서버 오류 메시지 (평소에는 숨김) |

## 4. 동작

| 요소 | 사용자 동작 | 결과 |
|---|---|---|
| 로그인 버튼 | 클릭 | 아이디와 비밀번호가 비었는지만 검사한다(형식은 검사하지 않음). 비었으면 칸 아래 오류. 아니면 POST /api/auth/login 호출. 성공하면 응답 redirectUrl로 이동(일반 사용자 /History, 관리자 /Admin/Send) |
| 아이디, 비밀번호 칸 | Enter 키 | 로그인 버튼을 누른 것과 같다 |
| 아이디, 비밀번호 칸 | 입력 | 그 칸의 오류 메시지와 전체 오류 알림을 지운다 |
| 회원가입 링크 | 클릭 | 회원가입 화면(/Account/Register)으로 이동 |

### API 오류 표시 위치
| 오류 코드 | 표시 위치 | 메시지 |
|---|---|---|
| LOGIN_FAILED | 전체 오류 알림 | 아이디 또는 비밀번호가 맞지 않습니다. (어느 쪽이 틀렸는지 알리지 않음) |
| INVALID_INPUT | 전체 오류 알림 | 서버가 보낸 message |
| INTERNAL_ERROR, 네트워크 오류 | 전체 오류 알림 | 오류가 발생했습니다. 잠시 후 다시 시도해 주세요. |

- 로그인에 실패하면 비밀번호 칸을 비우고 비밀번호 칸에 커서를 둔다.
