# Register_screen.md

회원가입 화면 설계 문서다. docs/screen.md 템플릿을 복사해서 작성했다.

화면을 바꾸는 작업에서는 이 문서도 함께 갱신한다.

## 1. 기본 정보

- **화면 파일 경로**: 프로젝트/src/Newsletter/Views/Account/Register.cshtml
- **화면 이름**: 회원가입
- **화면 목적**: 비회원이 아이디, 비밀번호, 이메일, 이름을 입력하고, 이메일 인증 코드를 받아 확인한 뒤 가입한다 (D-019, D-020, D-047)
- **접근 URL**: /Account/Register
- **접근 권한**: 비회원 (로그인 필요 없음)
- **시안 파일 경로**: 프로젝트/docs/mockups/register.html
- **연결 파일**: 프로젝트/src/Newsletter/wwwroot/js/register.js, 프로젝트/src/Newsletter/wwwroot/css/register.css

## 3. 화면 요소

| 요소 | 종류 | 표시 내용 | 데이터 출처 | 비고 |
|---|---|---|---|---|
| 서비스 이름 | 텍스트 | "뉴스레터" | 고정 문구 | |
| 화면 제목 | 텍스트 | "회원가입" | 고정 문구 | |
| 전체 오류 알림 | 알림 박스 | 오류 메시지 | API 오류 응답 message | 평소 숨김 |
| 아이디 | 입력칸 (text) | 안내 문구 "영문 소문자, 숫자 6~20자" | 입력값 → users.login_id | maxlength 20 |
| 비밀번호 | 입력칸 (password) | 안내 문구 "8~20자, 영문·숫자·특수문자 각 1자 이상" | 입력값 → users.password_hash (해시) | maxlength 20 |
| 비밀번호 확인 | 입력칸 (password) | 안내 문구 "비밀번호를 한 번 더 입력" | 입력값 (서버로 보내지 않음) | maxlength 20. 비밀번호와 다르면 "비밀번호가 일치하지 않습니다." (D-065) |
| 이메일 | 입력칸 (email) | 안내 문구 "인증 코드를 받을 이메일" | 입력값 → users.email | maxlength 50 |
| 인증 코드 발송 버튼 | 버튼 | "인증 코드 발송" / 한 번 보낸 뒤 "재발송" | | 이메일 오른쪽 |
| 인증 코드 | 입력칸 (text, 숫자만) | 안내 문구 "메일로 받은 6자리 숫자" | 입력값 | maxlength 6. 코드를 보내기 전에는 비활성 |
| 남은 시간 | 텍스트 | "남은 시간 09:59" 형식 | 발송 API 응답 expiresAt | 인증 코드 칸 오른쪽. 코드를 보낸 뒤에만 표시 |
| 인증 확인 버튼 | 버튼 | "확인" | | 코드를 보내기 전에는 비활성 |
| 인증 완료 표시 | 텍스트 | "이메일 인증이 완료되었습니다." (초록색) | 확인 API 응답 | 인증 성공 후에만 표시 |
| 이름 | 입력칸 (text) | 안내 문구 "2~30자" | 입력값 → users.name | maxlength 30 |
| 입력칸 오류 메시지 | 텍스트 (빨간색) | 각 입력칸 아래 오류 메시지 | 화면 검증 / API 오류 | 오류가 있을 때만 표시 |
| 입력칸 정상 표시 | 테두리 (초록색) + 체크 아이콘 | 규칙에 맞는 입력칸 | 화면 검증 | 부트스트랩 is-valid (D-067) |
| 가입 버튼 | 버튼 | "가입하기" | | 이메일 인증 완료 전에는 비활성 |
| 로그인 링크 | 링크 | "이미 계정이 있나요? 로그인" | | /Account/Login |

## 4. 동작

| 요소 | 사용자 동작 | 결과 |
|---|---|---|
| 각 입력칸 (아이디, 비밀번호, 비밀번호 확인, 이메일, 이름) | 글자를 입력하거나 지울 때마다, 그리고 칸을 벗어날 때 | 입력값 규칙(D-052)을 바로 검사한다(D-067). 틀리면 빨간 테두리와 칸 아래 오류 메시지, 맞으면 초록 테두리와 체크 표시 |
| 비밀번호 확인 | 글자를 입력할 때마다, 또는 비밀번호를 바꿀 때 | 비밀번호와 다르면 "비밀번호가 일치하지 않습니다.", 같으면 초록 표시. 가입 버튼을 눌렀을 때도 검사한다 |
| 인증 코드 | 글자를 입력할 때마다 | 6자리 숫자인지 바로 검사한다. 코드가 만료된 뒤에는 만료 메시지를 그대로 둔다 |
| 인증 코드 발송 버튼 | 클릭 | 이메일 형식을 검사한 뒤, 응답을 기다리지 않고 바로 "코드 발송 후" 화면으로 바꾼다(D-069): 인증 코드 칸과 확인 버튼 활성화, 10분 카운트다운 시작, 버튼 문구 "재발송". 동시에 POST /api/email-verifications를 호출하고, 응답이 오면 남은 시간을 서버 만료 시각에 맞춘다. 발송에 실패하면 처음 상태로 되돌리고 오류를 표시한다. 응답이 올 때까지 발송 버튼만 비활성 |
| 재발송 버튼 | 클릭 | 발송 버튼과 같이 바로 화면을 바꾸고 카운트다운을 10분으로 다시 시작한다. 성공하면 이전 코드는 쓸 수 없다. 실패하면 이전 코드의 남은 시간으로 되돌린다(이전 코드는 그대로 쓸 수 있음) |
| 인증 확인 버튼 | 클릭 | 6자리 숫자인지 검사한 뒤 POST /api/email-verifications/confirm 호출. 성공하면 인증 완료 표시, 이메일 칸·인증 코드 칸·발송 버튼·확인 버튼을 잠그고 가입 버튼을 활성화한다 |
| 남은 시간 | 0이 됨 | "인증 코드가 만료되었습니다. 재발송해 주세요." 메시지를 표시하고 확인 버튼을 비활성화한다 |
| 가입 버튼 | 클릭 | 모든 입력칸을 검사한 뒤 POST /api/users 호출. 성공하면 "가입이 완료되었습니다." 알림 후 로그인 화면(/Account/Login)으로 이동한다 |
| 로그인 링크 | 클릭 | 로그인 화면(/Account/Login)으로 이동한다 |

### API 오류 표시 위치
| 오류 코드 | 표시 위치 | 메시지 |
|---|---|---|
| INVALID_INPUT | 해당 입력칸 아래 (알 수 없으면 전체 오류 알림) | 서버가 보낸 message |
| LOGIN_ID_DUPLICATED | 아이디 칸 아래 | 이미 사용 중인 아이디입니다. |
| EMAIL_DUPLICATED | 이메일 칸 아래 | 이미 사용 중인 이메일입니다. |
| VERIFICATION_CODE_INVALID | 인증 코드 칸 아래 | 인증 코드가 맞지 않습니다. (남은 횟수 n번) |
| VERIFICATION_CODE_EXPIRED | 인증 코드 칸 아래 | 인증 코드가 만료되었습니다. 재발송해 주세요. |
| VERIFICATION_CODE_LOCKED | 인증 코드 칸 아래. 확인 버튼 비활성, 남은 시간 빨간색 | 인증 코드를 5번 틀려 더 이상 쓸 수 없습니다. 재발송해 주세요. (D-068) |
| NOT_FOUND (코드 확인) | 인증 코드 칸 아래 | 인증 코드를 먼저 발송해 주세요. |
| EMAIL_NOT_VERIFIED | 이메일 칸 아래 | 이메일 인증을 완료해 주세요. |
| MAIL_SEND_FAILED | 전체 오류 알림 | 인증 코드 메일을 보내지 못했습니다. 잠시 후 다시 시도해 주세요. |
| INTERNAL_ERROR, 네트워크 오류 | 전체 오류 알림 | 오류가 발생했습니다. 잠시 후 다시 시도해 주세요. |

## 6. 상태별 화면

| 상태 | 표시 내용 |
|---|---|
| 처음 열었을 때 | 모든 입력칸 비어 있음. 인증 코드 칸·확인 버튼·가입 버튼 비활성. 남은 시간, 인증 완료 표시, 오류 메시지 숨김 |
| 코드 발송 요청 중 | "코드 발송 후" 화면과 같다. "재발송" 버튼만 응답이 올 때까지 비활성 (D-069) |
| 코드 발송 후 | 인증 코드 칸·확인 버튼 활성, 남은 시간 카운트다운 표시, 발송 버튼 문구 "재발송" |
| 코드 만료 | 남은 시간 "00:00", 인증 코드 칸 아래 만료 메시지, 확인 버튼 비활성 |
| 코드 무효 (5번 틀림) | 인증 코드 칸 아래 무효 메시지, 확인 버튼 비활성, 남은 시간 빨간색. 재발송하면 처음부터 다시 |
| 인증 완료 | 인증 완료 표시(초록색), 이메일·인증 관련 칸과 버튼 잠금, 가입 버튼 활성 |
| 가입 처리 중 | 가입 버튼 비활성, 문구 "처리 중..." |
| 입력값 오류 | 해당 칸 테두리 빨간색, 칸 아래 오류 메시지 |
| 입력값 정상 | 해당 칸 테두리 초록색, 체크 아이콘. 인증 완료 후 이메일·인증 코드 칸도 초록 표시 |
| 서버 오류 | 상단 전체 오류 알림 표시 |
| 데이터 없음 | 해당 없음 (조회 화면이 아님) |
